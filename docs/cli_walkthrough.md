# Executable CLI walkthrough

This page is generated by executing every `protein-fasta` command against two deterministic
50-entry UniProtKB FASTA files and one 50-entry mixed UniProtKB/RefSeq file. The console blocks
below are not pasted examples: Zensical runs them during `make docs`, captures their output, and
fails the documentation build if any command exits non-zero.

`$WORK` is a fresh temporary directory used only for this documentation build.

{{ cli('cp "$WORK/alpha.fasta" "$WORK/beta.fasta" "$WORK/registry-input/"') }}

## Apply only the UniProtKB parser to a mixed database
